# Система групповых чатов для лобби

## Описание
Добавлена функция группового чата внутри игровых групп (лобби). Теперь участники группы могут общаться не только через внешние мессенджеры (по ссылке), но и прямо на сайте.

## Что было реализовано

### 1. База данных
- **Миграция**: `2025_01_13_120000_create_group_messages_table.php`
- **Таблица**: `group_messages`
- **Поля**:
  - `id` - ID сообщения
  - `game_group_id` - ID группы (связь с `game_groups`)
  - `user_id` - ID автора сообщения (связь с `users`)
  - `message` - текст сообщения (до 1000 символов)
  - `created_at`, `updated_at` - временные метки

### 2. Модели
- **GroupMessage** (`app/Models/GroupMessage.php`)
  - Связь с группой `gameGroup()`
  - Связь с пользователем `user()`
  
- **GameGroup** (обновлена)
  - Добавлена связь `messages()` для получения сообщений группы

### 3. Контроллер
- **GroupMessageController** (`app/Http/Controllers/GroupMessageController.php`)
  - `getMessages($groupId)` - получить все сообщения группы
  - `sendMessage(Request $request, $groupId)` - отправить сообщение в группу
  - Проверка прав доступа (только участники группы могут видеть и отправлять сообщения)

### 4. Маршруты
Добавлены в `routes/web.php`:
```php
Route::get('/groups/{group}/messages', [GroupMessageController::class, 'getMessages']);
Route::post('/groups/{group}/messages', [GroupMessageController::class, 'sendMessage']);
```

### 5. Интерфейс (Community.vue)

#### Кнопка "ЧАТ"
- Отображается только для участников и создателя группы
- Расположена рядом с кнопками "УЧАСТНИКИ" и "ПОКИНУТЬ"/"УДАЛИТЬ"
- Зеленый цвет для отличия от других кнопок

#### Модальное окно чата
- **Заголовок**: название группы + "Групповой чат"
- **Область сообщений**:
  - Автоматическая прокрутка к последнему сообщению
  - Отображение аватара и имени отправителя
  - Временные метки (умный формат: сегодня - время, вчера - "Вчера + время", раньше - дата + время)
- **Поле ввода**:
  - Максимум 1000 символов
  - Отправка по Enter или кнопке "ОТПРАВИТЬ"
- **Автообновление**: сообщения обновляются каждые 3 секунды

#### Функционал
- `openGroupChat(group)` - открыть чат группы
- `closeGroupChat()` - закрыть чат (с очисткой интервала обновления)
- `loadGroupChatMessages()` - загрузить сообщения
- `sendGroupMessage()` - отправить сообщение
- `scrollToBottomGroupChat()` - прокрутка к последнему сообщению
- `formatMessageTime(date)` - форматирование времени

## Как использовать

### Для пользователей:
1. Перейти на страницу "СООБЩЕСТВО"
2. Выбрать вкладку "ГРУППЫ"
3. Найти группу, в которой вы состоите (или создать новую)
4. Нажать зеленую кнопку "ЧАТ"
5. Отправлять сообщения всем участникам группы

### Особенности:
- Чат доступен только участникам группы
- Сообщения видны всем участникам в реальном времени (обновление каждые 3 секунды)
- История сообщений сохраняется в базе данных
- При закрытии чата автообновление останавливается

## Безопасность
- Проверка членства в группе перед доступом к сообщениям
- Валидация длины сообщения (макс. 1000 символов)
- Защита от SQL-инъекций через Eloquent ORM
- Cascade удаление сообщений при удалении группы или пользователя

## Технические детали

### Зависимости:
- Vue 3 (Composition API)
- Axios для API запросов
- Laravel 11

### API endpoints:
- `GET /api/community/groups/{group}/messages` - получить сообщения
- `POST /api/community/groups/{group}/messages` - отправить сообщение

### Формат запроса для отправки:
```json
{
  "message": "Текст сообщения"
}
```

### Формат ответа:
```json
{
  "id": 1,
  "game_group_id": 5,
  "user_id": 10,
  "message": "Привет всем!",
  "created_at": "2025-01-13T12:00:00.000000Z",
  "user": {
    "id": 10,
    "name": "Player123",
    "avatar": "avatars/player123.jpg"
  }
}
```
