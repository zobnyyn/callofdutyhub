# Руководство: Изображения и встроенные предметы в гайдах

## 📸 Приближение изображений

### Возможности:
- **Клик по изображению** - открывает его в полноэкранном режиме (лайтбокс)
- **Колесико мыши** - приближение/отдаление изображения
- **Кнопки + и -** - управление зумом
- **Кнопка 1:1** - сброс зума к исходному размеру
- **Перетаскивание мыши** - перемещение приближенного изображения
- **Клик по фону или крестику** - закрытие лайтбокса
- **Индикатор зума** - показывает текущий уровень приближения в процентах

### Горячие клавиши:
- `ESC` - закрыть лайтбокс (можно добавить)
- Колесико мыши вверх - приблизить
- Колесико мыши вниз - отдалить

### Визуальные эффекты:
- При наведении на изображение в тексте оно подсвечивается оранжевой рамкой
- Курсор меняется на указатель, показывая что изображение кликабельно
- Плавные анимации при открытии/закрытии лайтбокса

## 🎮 Встроенные предметы в тексте гайда

### Как использовать:

При создании/редактировании гайда вы можете вставлять ссылки на предметы прямо в текст используя специальный HTML-код:

```html
<span class="guide-item">
  <img src="/storage/путь_к_иконке.png" alt="Название" class="guide-item-icon" />
  <span class="guide-item-name">Название предмета</span>
</span>
```

### Примеры использования:

#### Пример 1: Упоминание оружия
```html
<p>
  Для прохождения этого раунда рекомендую использовать 
  <span class="guide-item">
    <img src="/storage/weapons/raygun.png" alt="Ray Gun" class="guide-item-icon" />
    <span class="guide-item-name">Ray Gun</span>
  </span>
  вместе с 
  <span class="guide-item">
    <img src="/storage/weapons/thundergun.png" alt="Thundergun" class="guide-item-icon" />
    <span class="guide-item-name">Thundergun</span>
  </span>
</p>
```

#### Пример 2: Упоминание перков
```html
<p>
  Обязательно возьмите 
  <span class="guide-item">
    <img src="/storage/perks/juggernog.png" alt="Juggernog" class="guide-item-icon" />
    <span class="guide-item-name">Juggernog</span>
  </span>
  и 
  <span class="guide-item">
    <img src="/storage/perks/speed-cola.png" alt="Speed Cola" class="guide-item-icon" />
    <span class="guide-item-name">Speed Cola</span>
  </span>
  на ранних раундах.
</p>
```

#### Пример 3: Жвачки (Gobblegums)
```html
<p>
  Для этой стратегии идеально подходит 
  <span class="guide-item">
    <img src="/storage/gums/perkaholic.png" alt="Perkaholic" class="guide-item-icon" />
    <span class="guide-item-name">Perkaholic</span>
  </span>
</p>
```

### Визуальные особенности:

Встроенные предметы отображаются как:
- **Инлайн-блок** с иконкой и названием
- **Оранжевый градиентный фон** с рамкой в стиле игры
- **Моноширинный шрифт** для консистентности с общим дизайном
- **Hover-эффект**: при наведении предмет подсвечивается и немного поднимается
- **Иконка 20x20 пикселей** рядом с названием

## 🛠️ Для разработчиков

### Добавление поддержки в WYSIWYG-редактор

Если вы используете WYSIWYG-редактор (например, TinyMCE или FilamentPHP TipTap), можно добавить кнопку для вставки предметов:

```javascript
// Пример для TinyMCE
editor.ui.registry.addButton('insertGameItem', {
  text: 'Вставить предмет',
  onAction: function() {
    // Открыть модальное окно с выбором предмета
    openItemSelector().then(item => {
      editor.insertContent(`
        <span class="guide-item">
          <img src="${item.image}" alt="${item.name}" class="guide-item-icon" />
          <span class="guide-item-name">${item.name}</span>
        </span>
      `);
    });
  }
});
```

### Стили CSS

Все необходимые стили уже добавлены в компонент ShowGuide.vue:

```css
:deep(.guide-content .guide-item) {
  display: inline-flex;
  align-items: center;
  gap: 0.5rem;
  padding: 0.25rem 0.75rem;
  background: linear-gradient(135deg, rgba(249, 115, 22, 0.1), rgba(239, 68, 68, 0.1));
  border: 1px solid rgba(249, 115, 22, 0.3);
  border-radius: 0.25rem;
  /* ... остальные стили ... */
}
```

### Расширение функциональности

Можно добавить:
1. **Tooltip с описанием** при наведении на встроенный предмет
2. **Клик по предмету** - открытие модального окна с полной информацией
3. **Автодополнение** при наборе названия предмета в редакторе
4. **Шорткоды** типа `[item:raygun]` для упрощения вставки

## 📱 Адаптивность

Все функции работают на мобильных устройствах:
- **Лайтбокс изображений**: работает с touch-жестами (pinch-to-zoom можно добавить)
- **Встроенные предметы**: корректно отображаются на маленьких экранах
- **Responsive дизайн**: все элементы адаптируются под размер экрана

## ✅ Проверка работы

1. Откройте любой гайд с изображениями
2. Кликните по изображению - должен открыться лайтбокс
3. Попробуйте приблизить изображение колесиком мыши или кнопками +/-
4. Перетащите приближенное изображение мышью
5. Добавьте встроенные предметы в текст гайда при редактировании
6. Проверьте hover-эффект на встроенных предметах
